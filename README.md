# UniversalUI
A better version of my previously made UniversalUI which works in pretty much any game that you play. I made this keyless because I just hate when I want a hack script but I need to sit through a bunch of shitty ads, and its also open sourced so feel free to make your own versions!

Go our [website](https://sites.google.com/view/universal-ui) to find/publish custom modules for others to use.

Execute using:
```
loadstring(game:HttpGet("https://raw.githubusercontent.com/bradenbarlo/UniversalUI/refs/heads/main/UniversalUI%20Script"))()
```

> [!TIP]
> Look at all the UI functions to learn how they work and play around with it a little bit.
If you want to add custom modules, go to the [Custom Module Example](Custom%20Module%20Example) and it has the full custom module testing playground, and some simple instructions. Paste it into Roblox Studio to begin creating your module! The example is at the bottom of the script btw.
